Third-party software
====================

The offline Manager is a single HTML file written for this project. It contains no third-party code libraries and no embedded
language runtime; it runs in the browser's own JavaScript, WebHID and Web Crypto support.

It does carry the pinned factory dictionary files that the keyboard's factory dictionaries are built from (the Lapwing and Plover
sources listed in tools/dictionaries/manifest.py), so it can set up, restore and edit them without a network connection.
